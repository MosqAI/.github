# Contributing to MosqAI Shield

The full workflow is in
[mosqai-docs/workflow.md](https://github.com/MosqAI/mosqai-docs/blob/develop/workflow.md).
Short version:

1. Pick an issue from the board and assign yourself.
2. Branch from `develop`: `feature/…`, `fix/…`, or `refactor/…`.
3. Commit with Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `chore:`).
4. Open a PR into `develop` and fill in the template. One approval is needed (two for contract changes).
5. Never commit `.env` files, keys, tokens, or certificates.
